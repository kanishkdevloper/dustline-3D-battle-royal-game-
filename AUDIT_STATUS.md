# v1.0.19 static audit pass (offline, NOT compiled - no Kotlin compiler / Android SDK was available)
Checked: bracket balance of all 55 .kt files, every `renderer.* / map.* / Prefs.* / HudLayout.*` member used exists, all asset paths used in code exist (3 known optional leftovers: maps/viaduct.bin, maps/roadblob.bin, models/character/ - all inside try/catch), manifest.txt (93 entries, 0 size mismatch), resource XML + @refs, privacy-policy check, verify_map.py (MAP OK), dependency versions exist (play-services-ads 25.5.0 = 2026-09-17, user-messaging-platform 4.0.0 = 2025-10-31).
Fixed:
1. Timers / coordinates used `"%d:%02d".format(...)` with the PHONE's locale: on Marathi / Bengali / Nepali / Arabic phones the digits would be drawn in the local script. Now `String.format(Locale.US, ...)` (GameRenderer x2, GameScreen x2, ResultView, ZoneSystem) - same as ProfileView already did.
2. AssetPreloader: a stray space / tab in a manifest.txt line threw NumberFormatException and blocked the whole start-up ("Startup error"). Lines are trimmed now.
3. MainActivity: if the match map failed to load the loading screen showed the error but BACK only asked "press again to exit" (dead end). BACK now returns to the lobby (RETRY still works).
4. GameScreen minimap: a new String was built every frame only to compare the position (garbage / GC stutter). Now compares three floats.
5. EXIT button (in match) now needs a second tap within 2.5 s ("TAP EXIT AGAIN TO LEAVE THE MATCH") - no accidental quit (GameScreen).
6. Display cutout / notch: the HUD view is shrunk by the cutout + system-bar insets (max 12 % of the width per side), the 3D view stays full screen, so no button hides under the notch (GameScreen.applySafe).
7. A gun you drop keeps its magazine: Loot.ammo stores the rounds left; picking it up again restores that, fresh guns still come full (no more free refill by swapping).
Still open: nothing known. Needs one real build + a full match on a phone (notch phone for item 6).
